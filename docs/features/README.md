# Features

Un README por feature, a partir de [`docs/templates/feature.md`](../templates/feature.md). Índice:

| Feature | Qué hace |
|---|---|
| [auth](auth/README.md) | Login de todos (admin y pacientes) con JWT propio y rol en la sesión, y "Acceso denegado" en `/admin/**`. |
| [location](location/README.md) | Ubicaciones (consultorios y online), sus horarios semanales y la sección «Dónde atiendo» de la home. |
| [settings](settings/README.md) | Duración única de los turnos y lista de obras sociales. |
| [agenda](agenda/README.md) | Turnos, disponibilidad, bloqueos, agenda del panel y emails de turnos. |
| [patient](patient/README.md) | Cuentas de pacientes: registro, activación, «olvidé mi contraseña», «Mi espacio» y el ícono del hero. |
